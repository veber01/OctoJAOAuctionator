# Octo - Just another Auctionator 1.1.5

Tweaked fork of OctoAuctionator.

Your Auction buddy.
**Tweaked by Happyness.**

## Info
Make sure to disable any other Auction addons to prevent conflicts.

1.12.1 auction house browsing is quite slow, the client itself has a hard coded 5 second delay on searches, so i'd highly recommend using  `AuctionQueryThrottle.dll`. More info and download here [AuctionQueryThrottle](https://github.com/brues-code/AuctionQueryThrottle). It is loaded with [VanillaFixes](https://github.com/hannesmann/vanillafixes).

`/atr clear fullscandb` clears stored prices and `/atr clear posthistory` clears your post history.

## Install

1. Download **OctoJAOAuctionator-1.1.5.zip** from releases.
2. Extract it into your WoW `Interface/AddOns` folder.
3. Restart WoW and enable the addon.

## pfUI skin

If **pfUI** is installed, OctoAuctionator restyles itself to match your pfUI settings. Without pfUI nothing changes. To switch the skin off, remove the `Skin.lua` line from `OctoJAOAuctionator.toc`.
